## 11. PR #140 への添付方法

1. 本テンプレートを複製して全項目を記入します。
2. 証跡（スクリーンショット等）は**個人情報を含まない合成データのものだけ**を選びます。
3. **PR #140 にコメントとして**次の形式で投稿します:
   - 基本情報・端末・対象SHA
   - 完了条件のチェック結果
   - 結果サマリーと欠陥一覧
   - 証跡へのリンク（リポジトリ外の保存先）または添付ファイル（sanitized済みのみ）
4. 生logcat、OCR元文の生データ、実データのスクリーンショットは添付しません。
5. 投稿後、Issue #146 へ完了コメントを残し、総合判定を記録します。

# v0.7.0 リリースノート（日本語）

Google Play Consoleの「このリリースの新機能」へ転記する文面です。公開前に内部テスト結果と最終仕様を照合してください。

## 転記用

プリントや連絡文を、より手早くTodoにできるようになりました。

- PDFと複数画像の取り込みに対応
- 複数画像の順番変更と不要ページの除外に対応
- Todo候補と読み取り元の文章を見比べやすく改善
- 候補の一括修正・複数削除を改善
- 読み取り辞書の確認、個別削除、取り消し、全消去に対応
- 通知、データ復旧、取り込み失敗時の安全性を改善

# あしたもつもの サポート

最終更新日: 2026年7月15日

「あしたもつもの」は、学校・園などのお知らせをTodo、持ち物、期限、通知として整理するアプリです。

公開先予定: `https://lp-5t7.pages.dev/apps/ashita-motsumono/contact`

プライバシーポリシー正本: [`../privacy_policy.md`](../privacy_policy.md)

> 本文はサポートページ掲載用の原稿です。公開前に問い合わせフォームまたは返信可能なメールアドレスを設定してください。プライバシーに関する説明は正本と一致させてください。

## 主な機能

- 人物ごとのTodo管理
- 期限、カテゴリ、持ち物、金額、メモ、チェックリストの登録
- 期限前・当日の端末内通知
- カメラまたは端末内画像からの日本語OCR
- 購入者向けAI画像解析
- 広告除去の買い切り購入
- AI分析利用権の買い切り購入
- 購入の復元
- 登録データのJSONエクスポート
- 端末内データの一括削除

## よくある質問

### 通知が届きません

次を順に確認してください。

1. 端末の設定で「あしたもつもの」の通知が許可されているか確認します。
2. Todoに通知が設定され、通知予定時刻が未来であることを確認します。
3. 端末の日付、時刻、タイムゾーンが正しいことを確認します。
4. バッテリー節約、バックグラウンド制限、メーカー独自の自動起動制限を確認します。
5. アプリを一度起動し、通知の再予約処理を行います。
6. Androidでは端末再起動後またはアプリ更新後に一度アプリを起動して確認します。

通知を拒否してもTodoの登録・閲覧は利用できます。

### カメラが使えません

端末の設定でカメラ権限を許可してください。拒否したままでも、画像選択または手入力を利用できます。

Androidで権限を「今後表示しない」にした場合は、OSのアプリ情報画面から変更してください。

### 画像を選択できません

OSの写真・画像選択画面で対象画像を選択してください。OSバージョンによっては、選択した画像だけを一時的に利用する方式です。

### OCRで文字を読み取れません

- 画像を明るい場所で正面から撮影します。
- 文字が画面内で小さすぎないようにします。
- 影、反射、傾き、折り目を避けます。
- 日本語OCRに失敗した場合は、画像を撮り直すかテキスト貼り付け・手入力を利用します。

通常OCRは端末上で処理します。通常OCRの画像をAI解析サーバーへ送信しません。

### AI画像解析とは何ですか

AI分析利用権を購入済みの場合、手書きや複雑なお知らせの画像を解析してTodo候補を作成できます。

利用時は、画像選択前に外部送信の説明を表示します。「同意して画像を選ぶ」を選んだ場合だけ、画像、画像形式、解析基準日、タイムゾーンをCloudflare Workers経由でGoogle Gemini APIへ送信します。送信を望まない場合はキャンセルし、通常OCRまたは手入力を利用してください。

Google Gemini APIが生成したTodo候補は、アプリが受信する解析結果です。解析結果を入力データとしてGoogle Gemini APIへ再送信するものではありません。

AIの解析結果は誤る場合があります。期限、金額、持ち物、人物名等を必ず確認・修正してから登録してください。

### 購入したのに広告が表示されます

1. 購入時と同じGoogle PlayまたはAppleのアカウントであることを確認します。
2. インターネット接続を確認します。
3. 設定画面の「購入を復元」を実行します。
4. アプリを完全に終了して再起動します。
5. ストア側で購入が完了または復元済みであることを確認します。

広告除去とAI分析は別商品です。広告除去の購入だけではAI分析は有効にならず、AI分析の購入だけでは広告は非表示になりません。

購入状態は端末内の設定として保存されます。現在の実装では、購入状態、レシートまたは購入トークンを開発者の独自サーバーへ送信・保存しません。

### 購入ボタンが押せません

ストアに接続できない、商品が未公開、テストアカウントが未設定、商品IDがビルド設定と一致していない等の可能性があります。時間をおいて再試行し、内部テスト版ではテスター登録とストアの商品状態を確認してください。

既定の商品IDは次のとおりです。

- 広告除去: `remove_ads`
- AI分析: `ai_analysis`

本番ではビルド時設定により別の商品IDを使用する場合があります。

### 広告が表示されません

広告ユニット未設定、ネットワーク不通、広告在庫なし、同意状態、広告ブロック、審査中等により表示されない場合があります。広告が表示できなくてもTodo、OCR、通知等の主要機能は利用できる設計です。

### 登録データはクラウド同期されますか

いいえ。現在の実装には、開発者アカウント、ログイン、家族共有、Todo同期用の独自サーバーはありません。登録データは原則として利用端末内に保存されます。

端末変更時の自動移行は保証されません。OSのバックアップや移行機能の対象になるかはOS設定に依存します。

### データをエクスポートできますか

設定画面のエクスポート機能で、人物名、Todo、OCR処理済みテキストをJSONとしてクリップボードへコピーできます。画像本体と端末内画像パスは含みません。

クリップボードへコピーした内容には個人情報が含まれる場合があります。貼り付け先と共有先を確認してください。

### すべてのデータを削除するには

設定画面の「登録データをすべて削除」を使用してください。人物、Todo、読み取り履歴、保存画像、学習済み候補等が削除対象です。操作は元に戻せません。

アプリをアンインストールした場合も、OSの仕様に従ってアプリ専用領域のデータが削除されます。AI画像解析、広告等により外部サービスへ送信済みの情報には各サービスの保持方針が適用されます。ストアが管理する購入記録は、Google PlayまたはAppleのアカウント・ストア機能で管理されます。

### 起動時に「データを安全に復旧」と表示されます

端末内データベースを読み込めなかったため、データを上書きしないよう通常操作を停止しています。

1. まず「読み込みを再試行」を実行します。
2. 退避情報が表示された場合はコピーして保管します。
3. 改善しない場合のみ、内容を理解したうえで「端末内データを初期化」を選びます。

初期化は元に戻せません。退避ファイルからの手動復旧が必要な場合は、退避情報とアプリのバージョンを添えてお問い合わせください。退避ファイルそのものには個人情報が含まれ得るため、公開のIssueやSNSへアップロードしないでください。

### 障害ログは送信されますか

障害ログは端末内のアプリ専用領域に記録され、現在の実装では自動送信されません。問い合わせ時に、画面表示、再現手順、端末情報を利用者自身で共有していただく場合があります。

## お問い合わせ時に必要な情報

個人情報、画像原本、購入トークン、パスワード等を送信する前に、必要性を確認してください。通常は次の情報で調査できます。

- アプリ名: あしたもつもの
- アプリのバージョン
- OS名とOSバージョン
- 端末メーカー・機種名
- 発生日時とタイムゾーン
- 発生した画面・機能
- 再現手順
- 期待した結果と実際の結果
- 表示されたエラーメッセージ
- 通信環境（Wi-Fi / モバイル通信 / オフライン）
- 購入問題の場合は商品名、購入日時、ストア上の状態（注文番号は必要な場合のみ、安全な窓口で共有）

Todo内容、子どもの氏名、学校名、顔写真、住所、連絡先、購入トークン等は、原則として伏せてください。
